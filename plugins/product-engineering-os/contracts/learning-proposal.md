# Learning proposal contract v1

The normalized proposal is `peos/changes/<change_id>/learning-proposal.md` or a dedicated pull request changing `peos/guidelines/`.

It includes source human feedback or outcome, repetition/evidence, classification (`one-off`, `change-specific`, or `reusable`), affected product or engineering guideline, proposed minimal diff, examples and counterexamples, possible conflicts, owner, review criteria, and rollback/removal condition.

Only reusable feedback should normally become a guideline. No proposal is approved merely because an agent generated it.
