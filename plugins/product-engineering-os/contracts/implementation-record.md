# Implementation record contract v1

The implementation record is maintained in `peos/changes/<change_id>/implementation.md` when work spans more than a trivial edit.

It records the approved slice, repositories and files changed, contract/migration impact, intentional deviations from the spec, commands executed and outcomes, checks not run, rollout state, and remaining work. Link commits or pull requests when available. Never claim a deployment, approval, or live outcome without direct evidence.
