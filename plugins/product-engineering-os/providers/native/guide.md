# PEOS native adapter: guide

Read active change state when present, then use `references/routing.md` to select the smallest safe path. Do not invoke every role. Return the normalized guide decision, and continue into the next capability when the user has already asked for the underlying work.

When intent is product-ambiguous, choose `/shape`. When requirements are approved but technical impact is unclear, choose `/design`. When design is sufficient, choose `/plan` or `/build` for a genuinely quick change. Route production incidents, telemetry investigations, and operational data questions to `/diagnose`. After implementation choose `/verify`; choose `/sync` or `/learn` only from explicit intent.
