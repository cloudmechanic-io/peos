# BMAD adapter: plan

Use `bmad-create-epics-and-stories` for a feature or strategic delivery backlog and `bmad-sprint-planning` only when the client uses that level of coordination. For quick work, use the implementation slice from `bmad-spec` without creating ceremony.

Normalize to `contracts/delivery-plan.md`. Slices must trace to acceptance criteria and technical deltas, name affected repositories, state dependencies and temporary compatibility, and separate implementation from publication, deployment, and live validation. Jira creation belongs to `/sync`, never to planning by default.

If BMAD is unavailable, report the missing provider and installation command without changing the public capability.
