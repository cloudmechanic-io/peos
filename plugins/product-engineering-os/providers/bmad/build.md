# BMAD adapter: build

Use `bmad-build` for fast-flow/quick implementation or the BMAD development workflow selected by the installed `bmad` router for approved feature slices. Never treat the provider’s generic developer persona as a substitute for PEOS scope: load only the affected frontend, backend, and/or infrastructure role contracts and client guidelines.

Implement one approved delivery slice at a time. Preserve unrelated user changes. Keep requirements and design visible as constraints, update `contracts/implementation-record.md`, and escalate any material deviation before expanding scope. Run the repository’s cheapest relevant checks during implementation; full independent gating remains `/verify`.

If BMAD is unavailable, report the missing provider and installation command without changing the public capability.
